# 기술 문서

## 컨테이너
- 모든 데이터는 `PSP_GAME/USRDIR/CROW.PAK` 하나에 들어 있습니다. PAK 안에 PAK가 다시 들어 있고, 개별 파일은 `.zdv`(16바이트 헤더 + zlib)로 압축된 경우가 많습니다.
- `tools/tree.py` 가 PAK/ZDV를 재귀로 풀고, `tools/repack.py` 가 바뀐 파일만 다시 묶어(압축 포함) 원본 ISO 구조를 유지한 채 새 ISO를 씁니다. 패치 경로는 `.zdv` 를 뺀 펼친 경로(`app_init.pak/table/systemtext.bin` 등)입니다.

## 실행 파일
- 복호화한 EBOOT(ELF)를 수정한 뒤 `tools/sign.py` 로 다시 서명해 넣습니다.
- 데이터 세그먼트의 vaddr은 파일 오프셋 − 0xC0입니다. 문자열은 `lui/addiu` 쌍이나 데이터 포인터 표로 참조됩니다.
- 실행 파일 문자열 875개는 원래 자리 길이 안에 덮어씁니다(`work/trans/src/eboot.json`).
- 추출 대상에서 빠져 있던 짧은 서식 문자열(`%2d月` `%2d日` `%s型`, 계절, `円`, `個`, 호칭 토큰 `pn君` 등)은 `build.py` 에서 같은 바이트 길이로 직접 바꿉니다.
- 한글 한 글자밖에 들어가지 않는 1글자 한자 이름(零·白·鍵 등)과 주인공 기본 성은, 데이터 표의 포인터를 옆에 있는 읽는 법 문자열(한글 이름)로 돌립니다.
- 이름 입력 키보드: 0x2B1154 의 4바이트 항목(2바이트 Shift-JIS 코드) 표에서 히라가나·가타카나 페이지를 한글 음절 163자로 바꿉니다.

## 인코딩
- 게임은 Shift-JIS를 씁니다. `tools/kenc.py` 가 한글 음절을 세 글꼴에 모두 있는 한자 코드 자리(0x889F 이후)에 순서대로 배정하고, 같은 표(`work/font_ko/charmap.json`)로 글꼴 글리프를 그립니다.
- 세로쓰기 대사의 좁은 공백은 별도 코드에 빈 글리프(폭 5)를 둡니다.

## 텍스트
- **PWX**(`tools/pwx.py`): 대본. ASCII 명령 스트림 사이에 Shift-JIS 대사가 들어 있습니다. 메시지 단위로 바꾸고 오프셋 표를 다시 계산합니다. `{` 로 시작하는 제목 메시지는 공백 없이, 일반 대사는 14칸×3열로 자동 줄바꿈하고 페이지를 나눕니다.
- **KSF**: 선택지. 30바이트 고정 슬롯입니다.
- **CSVB**(`tools/csvb.py`): 데이터 표. 문자열 열만 다시 써서 표를 재구성합니다.

## 글꼴
- **IPK**(`tools/ipk.py`, `tools/fontgen.py`): 4bpp 글꼴 페이지 + 글자별 `(코드, 폭, 잉크 높이)` 표. 잉크 높이는 셀 높이 전체로 둡니다(작게 두면 글자 아래가 잘립니다).
- advfont14(14px): 서울한강체 B 13pt, sysfont18(18px): 서울한강체 EB 17pt, mobilefont(12px): 갈무리9 10px 비트맵.

## 텍스처
- **GIM**(`tools/gim.py`): 4/8비트 팔레트 또는 16/32비트, 16바이트×8줄 스위즐. 원본 팔레트를 유지하고 가장 가까운 색으로 다시 인코딩해 바뀌지 않은 픽셀은 원본과 같게 둡니다.
- **ZNTP**(`tools/znt.py`): 던전 3D 텍스처 묶음. `ZNTP, 크기, n` 뒤에 GIM 오프셋 n개(12 기준)와 이름 오프셋 n개(12+4n 기준).
- `tools/imgko.py` 가 스펙 JSON(`box`, `clear`, `text`, `font`, `size`, `stroke`, `vertical` 등)대로 일본어를 지우고 한글을 그립니다. 빌드할 때 내용 해시가 같은 GIM·ZNTP 텍스처 전부에 적용합니다.
- 많은 UI 이미지는 게임이 g2d 좌표로 잘라 붙이는 글자 조각이라, 한글을 원래 글자 영역 안에 그려야 합니다.

## 기타
- `tools/play.py`, `tools/emu.py`, `tools/ppsspp_rpc.py`: PPSSPP 원격 디버거(WebSocket)로 버튼 입력·화면 캡처·메모리 읽기를 해 실제 플레이로 검수합니다.
