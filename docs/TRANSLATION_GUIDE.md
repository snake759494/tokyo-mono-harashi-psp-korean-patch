# 번역 지침

- 외부 기계 번역을 쓰지 않고 직접 번역했습니다.
- 학원 전기물 분위기에 맞춰 대사는 인물별 말투(사투리·존댓말·반말)를 살린 구어체로, 용어 사전·Q&A는 설명체로 씁니다.
- 인명·지명은 일본어 발음대로 음역합니다(시치다이 카즈키, 카라스노모리 학원 등). 용어는 `work/trans/GLOSSARY.md` 의 표기를 따릅니다(봉찰사, 화찰, 카미후다 등).
- 대본의 제어 코드(`{PX}` `{PM}` `{PN}` 이름 치환, 루비 `l漢字(かな)`)와 서식 문자는 원문 그대로 유지합니다.
- 세로쓰기 대사는 한 열 14칸, 한 페이지 3열 기준으로 빌드할 때 자동 줄바꿈합니다. 띄어쓰기도 한 칸을 차지하므로 너무 길게 쓰지 않습니다.
- 선택지는 30바이트(한글 15자) 안에 들어가야 합니다.
- 실행 파일 문자열은 원래 자리 길이(`maxbytes`)를 넘을 수 없습니다. 한글 1자 = 2바이트입니다.
- 쓸 수 있는 글자는 KS X 1001 한글 2,350자와 대본에 실제로 쓰인 그 밖의 음절, 전각 기호, ASCII입니다.
- 그림 글자는 원래 글자 영역 안에 들어가야 합니다(게임이 그 영역을 잘라 붙여 씁니다).
